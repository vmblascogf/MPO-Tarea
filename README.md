# MPO-Tarea - Proyecto Web

Se trata de un proyecto web básico desarrollado utilizando HTML 
como parte de una actividad de aprendizaje de Git, GitHub y Markdown.

El objetivo es crear una web sencilla, implementar diferentes mejoras 
mediante ramas independientes y documentar el proceso de desarrollo.

## Mejoras implementadas

Se han desarrollado tres mejoras, cada una en una rama independiente:

1. **Formulario de contacto (feature/formulario-contacto)**
   - Campos para nombre, correo electrónico, asunto y mensaje.
   - Botón de envío.
   - Estructura HTML sin funcionalidad de envío.

2. **Galería de imágenes (feature/galeria-imagenes)**
   - Incorporación de tres imágenes.
   - Descripciones mediante etiquetas figcaption.
   - Organización del contenido con elementos figure.

3. **Footer con redes sociales (feature/footer-redes-sociales)**
   - Pie de página con enlaces a Facebook, Instagram, X y YouTube.
   - Texto de copyright.

Todas las mejoras se han integrado en la rama principal mediante Pull Requests.

## Tecnologías utilizadas

- **HTML5:** creación y estructuración del contenido web.
- **Git:** control de versiones y gestión de ramas.
- **GitHub:** alojamiento del repositorio y gestión de Pull Requests.
- **Markdown:** documentación del proyecto.
